#
# 由 requirements.txt + requirements-ui.txt 安裝完成後，喺 .venv-ui 以 pip freeze 產生：
#   .venv-ui/Scripts/python.exe -m pip freeze --exclude-editable | sort > 內容
#
# 為何要鎖：requirements*.txt 刻意用 >=（開發時方便），但交付畀第二台機時，
# 浮動版本會裝到未測過嘅 numpy / ttkbootstrap，而本 UI 對 ttk 主題內部改動敏感。
#
# 基準環境：Windows 10/11 x64 + CPython 3.13.15（見 DEPLOY.md §0）
# 若改用其他 Python 版本，請先確認 pillow / numpy / pygame 有對應 wheel，否則此檔會裝唔起。
#
# 安裝（run_ui.bat 首次執行會自動做；手動等效命令）：
#   py -3 -m venv .venv-ui
#   .venv-ui\Scripts\python.exe -m pip install -r requirements.lock.txt
