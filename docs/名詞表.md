## 0. 三秒看懂：一句歌詞的生命週期

```
【ADR-012 後嘅管線 · 三條命令】

generate：
原始 MV ──[音訊抽取 16k mono]──► TempAudio
        ──[可選人聲分離]──────► Vocals
        ──[上傳 → 預簽名 URL]─► UploadedURL
        ──[ASR 異步轉寫]──────► AsrSentence[]（含 WordSlot[]）
        ──[拆字]──────────────► WordGroup[]（內含 CharSlot[]）
        ──[正規化]────────────► OpenCC s2hk（有 CJK 先跑）
        ──[斷句·標點優先]──────► LyricLine[]（ADR-013）
        ──[序列化]────────────► TimingsDoc（*_timings.json）← **canonical**
        ──[渲染]──────────────► KaraokeAss（衍生物）

render：  TimingsDoc ──► KaraokeAss        （毋須重跑 ASR）
burn：    影片 + KaraokeAss ──► *_karaoke.mp4（淨係食 ass，唔會隱含 render）
```

## 1. 單位對照表（寫錯一個就全線走位移）

| 單位 | 全稱 | 換算 | 出現位置 | 備註 |
|---|---|---|---|---|
| **ms** | millisecond 毫秒 | 1 ms = 1/1000 s | 百煉 API 所有 `begin_time` / `end_time` | API 唯一時間單位 |
| **cs** | centisecond 百分秒 | **1 cs = 10 ms** | ASS `\k` `\kf` `\K` `\ko` 的參數 | ⚠️ 換算必須 `duration_cs = max(1, round(ms / 10))` |
| s | second 秒 | — | `original_duration_in_milliseconds` 之外的少數字段 | 見 A-7 陷阱 |
| — | ASS 時間戳 | `H:MM:SS.cc` | Dialogue event 的 Start / End | ⚠️ 見 C-6 |

**記憶口訣**：API 講 ms，ASS 講 cs，**相差 10 倍**。所有跨越呢條界線嘅運算，必須集中喺同一個 helper（`ms_to_cs`），唔准散落。（違反 → 見 ADR-005）

## 2. A 組：阿里百煉 / DashScope ASR

| 術語 | 定義 | 陷阱 / 實測結論 |
|---|---|---|
| **Filetrans** | 「錄音文件轉寫」類模型，走**異步任務**協議：提交 → 輪詢 → 下載結果 JSON。本專案用 `qwen-audio-3.1-asr-flash-filetrans` | 異步提交需 header `X-DashScope-Async: enable`（SDK 內部處理） |
| **task_id** | 提交轉寫任務後 cloud 返回的任務識別碼，之後用佢輪詢 | 唔好同 `request_id` 混 |
| **task_status** | 任務整體狀態：`PENDING` / `RUNNING` / `SUCCEEDED` / `FAILED` | |
| **subtask_status** | `results[]` 陣列**內每一筆**的狀態（一個 task 可含多個檔案） | ⚠️ **必須逐筆檢查**，只 check `task_status` 會漏錯 |
| **transcription_url** | 位於 `output['results'][i]['transcription_url']`，指向可下載的完整結果 JSON（帶時效簽名） | ⚠️ 本 model 係 **`results`（複數）**；`result`（單數）係 `qwen3-asr-*` 系列嘅格式，唔好 hardcode 錯（見 ADR-003） |
| **file_urls** | 提交時的輸入參數，**array，每次只准 1 個 URL** | ⚠️ `qwen3-asr-flash-filetrans` 用單數 `file_url`，DashScope SDK 嘅 `Transcription.async_call` 硬編寫 `file_urls`，因此 **SDK 叫唔到 qwen3 系列** |
| **oss:// URL** | `dashscope.utils.oss_utils.OssUtils.upload()` 返回的臨時雲端路徑，如 `oss://dashscope-instant/<uid>/<date>/<uuid>/sample.wav` | ⚠️ **直接提交會 FAILED**：`REQUEST_INVALID_FILE_URL_VALUE`。必須同時傳 `headers={"X-DashScope-OssResourceResolve": "enable"}` |
| **UploadedURL** | 本專案內部用詞：最終餵畀 API 嗰條 URL。目前策略係用 `Files.upload → Files.get()` 攞到嘅**預簽名 https URL** | 另一條可行路係 oss:// + header，已實測可行但列為後備（見 ADR-003） |
| **language_hints** | 可選參數，array，最多 4 個值，提示輸入音訊語種 | ⚠️ **本專案最危險嘅參數**，見下兩行 |
|   ↳ `language_hints=['zh']` | ✅ **唯一能保留粵語口語字**嘅設定。實測 21 字 ground truth 全中：`我哋／一齐／食饭／唔／埋／银包` | 本專案 `--language yue` 會被**內部重映射**做 `['zh']`（ADR-001） |
|   ↳ `language_hints=['yue']` | ⚠️ **毒藥**。實測輸出 `我们今晚一起去吃饭啦，你不要不记得带上个钱包。` —— 觸發「粵語→普通話書面語」轉寫，粵字全數蒸發 **[禁用：直接傳 yue]** | 官方語言碼清單亦**冇 `yue`** |
| **sentences[]** | 結果 JSON 中 `transcripts[0].sentences[]`，句級單位，含 `begin_time` / `end_time` / `text` / `sentence_id` / `words` | |
| **words[] · WordSlot** | 句內的字/詞單位。每筆含 `text` / `begin_time` / `end_time` / **`punctuation`** / **`confidence`** | ⚠️ `punctuation` 係**跟喺該 word 後面**嘅標點（如 `' world'` 帶 `punctuation='，'`），唔係獨立 word |
| **punctuation** | 附屬喺 WordSlot 尾部嘅標點符號字串，無則為 `""` | ⚠️ **ADR-013 後**：唔再黐落 CharSlot.text，改存 `WordGroup.punctuation` 獨立字段；`CharSlot` 永遠純字 |
| **分句 / Clause** | **ADR-013 新增**：由「帶 `punctuation` 或 `sentence_end` 嘅 WordGroup」收結嘅一群 WordGroup，係標點優先斷行嘅基本單位 | 實測《普渡眾生》32 個分句，最長 13 字、最短 4 字 |
| **break_reason** | **ADR-013 新增**：`LyricLine.break_reason`，記錄嗰行係點斷出嚟：`punctuation` / `sentence` / `max_chars` / `gap` | 寫入 timings.json `lines[].break_reason`；debug 同日後 UI 提示用 |
| **display_text()** | **ADR-013 新增**：`LyricLine.display_text(strip_punctuation=True)`，顯示用文字。統一規則：**行尾標點 → 剝走；行中標點 → 半形空格** | `LyricLine.text` 係純字拼接；要顯示一律行呢個 method |
| **confidence** | 該 WordSlot 的信心值 | ⚠️ **`qwen-audio-3.1` 永遠回傳 1.0（無鑑別力）**；`fun-asr` 回傳真值（實測 0.94~1.0）。本專案唔用佢做過濾 |
| **多字詞 / MultiCharChunk** | 本專案用詞：`words[]` 中 `text` 去掉標點後**含 ≥2 個漢字**嘅 WordSlot，如 `今晚` `记得` `一齐` | 必須拆字，見 C-4。實測 `qwen-audio-3.1 + zh` 有 18 個 WordSlot / 21 字 = **86% 粒度** |
| **enable_words** | DashScope 參數 | ⚠️ 官方文件中**只屬於 `qwen3-asr-flash-filetrans`**。本 model 唔適用，且 word-level **本來就自帶**。實測傳咗結果無差異 **[禁用]**（ADR-002） |
| **enable_itn** | DashScope 參數（Inverse Text Normalization） | ⚠️ 只存在於 `qwen3-asr-flash` 的 **OpenAI 兼容模式** `asr_options`。本 model **冇呢個參數** **[禁用]**（ADR-002） |
| **content_duration_in_milliseconds** | `transcripts[0]` 下，**實際有語音內容**的長度 | 通常短於下一項 |
| **original_duration_in_milliseconds** | `properties` 下，**整段音訊檔**的長度 | ⚠️ 兩者同名尾巴但意義唔同，做進度條要用正確嗰個 |
| **usage.input_tokens** | 計費用量。`qwen-audio-3.1` 有；**`fun-asr` 冇 `usage` 字段**（實測為 `None`） | 若 code 要印費用，要容許 `None` |

## 4. C 組：ASS / libass / ffmpeg

| 術語 | 定義 | 陷阱 |
|---|---|---|
| **PlayResX / PlayResY** | `[Script Info]` 入面的「字幕腳本座標系」解析度。所有座標、字級都相對佢 | ⚠️ 本專案 **必須由 ffprobe 讀取原片解像度後填入**，唔准寫死 1920x1080（ADR-006） |
| **original_size** | ffmpeg `ass` filter 的選項：`original_size=WxH` | 告訴 libass「原片幾大」。唔加，字幕會按輸出 canvas 重新縮放而**走位** |
| **Alignment** | 字幕定位。`2` = 底部置中（本專案唯一取值） | 呢個係 **numpad 方位碼**，唔係 1-9 順序 |
| **MarginV** | 底部垂直留白（pixel，PlayRes 座標系） | 太小會貼死畫面邊緣 |
| **WrapStyle** | 換行策略。`2` = 唔換行（no word wrap） | 本專案靠自己嘅斷句邏輯控制，依賴 libass 換行會失控 |
| **\kf** | Karaoke **Sweep (Fill)** 標籤：`{\kf<cs>}文字`。變色邊界平滑掃過該字 | 本專案唯一使用嘅卡拉OK標籤 |
| **\k** | 硬切換：定時一到，**成個字**由底色跳去高亮色。本專案**只用嚟做停頓補償**（空能夠 Emission `\k<gap_cs>` 不帶文字） | 見 C-5 |
| **\K / \ko** | 其他卡拉OK模式（一次掃過／描邊） | **[禁用]** |
| **PrimaryColour** | Style 字段。**本專案語義：唱過（已 High 亮）嗰截嘅顏色** | 用户 `--primary-color` |
| **SecondaryColour** | Style 字段。**本專案語義：仲未唱到嗰截嘅底色** | 用户 `--secondary-color` |
| **OutlineColour** | Style 字段，字體外框顏色 | 用户 `--outline-color`。⚠️ 唔好叫 TertiaryColour（ASS v4.00 舊名） |

| **Dialogue event** | `[Events]` 入面一行字幕：`Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text` | 9 個逗號分隔欄位，Text 欄本身可以含逗號。⚠️ 取 Text 欄必須用 `line.split(",", 9)[9]`（maxsplit=9）；用 `split(",,")` 或 `split(",")` 會錯誤撈到 Margin 的 `0,0,0,`（見 ADR-011 評估腳本踩過的坑） |

### C-4 · 拆字（WordSlot → CharSlot）
`words[]` 出廠嗰刻，多字詞內部嘅子字時間軸**已經物理消失**。任何雲端 API 都無法還原，LLM 更加只能「估」（估出嚟嘅唔係時間軸）。
→ 本專案唯一做法：**按比例平分**。

```
WordSlot('今晚', 640, 920)            # 280ms
  → CharSlot('今', 640, 780)          # 140ms
  → CharSlot('晚', 780, 920)          # 140ms
```
例外：**純拉丁字母 word（`hello` / `world`）整體保留唔拆**，否則英文歌詞會變成逐字母閃。

### C-5 · 停頓補償（Gap Handling）
同一條 LyricLine 內，若「前一個 CharSlot 的 `end_ms`」與「下一個的 `begin_ms`」相差 **> 50 ms**，喺兩者之間插入**不帶文字**的 `{\k<gap_cs>}`，令高亮進度停留，避免提前變色。

### C-6 · ASS 時間戳格式（本專案最貴嘅一課）
```
正確：  0:00:00.28      ← H:MM:SS.cc
錯誤：  0:00:28         ← M:SS:cc  [禁用]
```
⚠️ 寫錯時 ffmpeg **唔會報錯退出**，只會喺 verbose log 印 `Bad timestamp`，然後**輸出一條完全冇字幕、而且 file size 同輸入一樣嘅 mp4**。極難 debug。

## 6. E 組：LLM 歌詞校正 —— ⚠️ **已移除（ADR-012）**

> **本組係歷史紀錄**。歌詞校正功能已喺 ADR-012 由 CLI 徹底移除：
> 本工具範圍收窄為「粵/國/英嘅**書面語**歌」，錯字交由字幕編輯 UI 人手修正；
> 而 ADR-011 實測校正淨收益只係 −1 ~ +2 字，卻要等多 2～7.5 分鐘。
>
> E-2（語體 Register）嘅概念**仍然重要** —— 因為本工具只處理書面語歌，
> 若日後重新引入任何文字修正功能，必須遵守「唔准改寫語體」。
> 下層技術內容保留作參考。

| 術語 | 定義 |
|---|---|
| **歌詞校正 / Correction** | 用 Qwen 文本模型修正 ASR 錯字，同時做「書面語 → 粵語口語」還原 |
| **字數鎖 / CharLock** | 校正後每行字數必須 === 校正前。**程式端強制驗證，唔夾就棄用校正結果、退回原文** |
| **思考模式 / thinking** | Qwen3.8 系列的推理機制，透過 `extra_body={"enable_thinking": False}` 關閉 |
| **reasoning_tokens** | `usage.completion_tokens_details.reasoning_tokens`，思考模式產生的 token |

### E-2 · 語體（Register）．**2026-10-29 真實 MV 後新增**

**點解要立呢條**（真實MV 實測，同一份 ASR、同一 model、淨係換 prompt）：

| 策略 | 相似度 | 正確字數 |
|---|---|---|
| 唔校正 | 89.54% | 214/239 |
| **強制口語化**（初版 prompt） | 80.75% | 193/239 ← **−21 字** |
| **保留語體**（現行 prompt） | **90.38%** | **216/239** |

→ **LLM 無從判斷一首歌係書面語定口語**，強制改寫必然錯一半。香港流行曲有大量書面語歌詞（林家謙、陳奕迅、張敬軒不少作品），呢個唔係邊緣案例。（ADR-011）

**禁止嘅語體轉換**（寫喺 `CORRECTION_SYSTEM_PROMPT` 入面）：
`的↛嘅` `不↛唔` `這↛呢` `來↛嚟` `給↛畀` `了↛咗` `還↛仲`

### E-3 · 非確定性（Nondeterminism）

同一段 MV 跑兩次：**ASR** 出 13 句 vs 12 句、字數 239 vs 238、逗號位置有差異；
**LLM 校正**同一 prompt 亦有明顯唔同 output。即使 `temperature=0.0`。
→ **字幕質素每次跑都有波動**，唔好當係 deterministic pipeline。

## 7. F 組：timings.json（canonical interchange format）· ADR-012

| 術語 | 定義 |
|---|---|
| **timings.json / TimingsDoc** | 本專案嘅 **canonical source of truth**。`.ass` 係由佢渲染出嚟嘅**衍生物** |
| **schema_version** | 目前係 `1`。加字段要 bump 版本並更新 ADR-012 |
| **`lines[]`** | 每行一條：`start_ms` / `end_ms`（**絕對值，render 直接用唔重算**）/ `text` / `words[]` |
| **`words[]`** | 兩層結構嘅外層：`text` / `begin_ms` / `end_ms` / **`estimated`** / `chars[]` |
| **`chars[]`** | 兩層結構嘅內層：`text` / `begin_ms` / `end_ms`（全部絕對 ms） |
| **`style`** | self-contained 的字幕樣式（含 `font_name` / `primary_color` / `margin_v` 等），令 `render` 唔使外部參數 |
| **`source`** | 產生呢份 json 嘅中繼資料（model、language_hints、asr_content_duration_ms、generated_at 等），**純記錄用途** |
| **dashboard 術語 `estimated`** | 見 B 組。UI 嘅核心提示：True = 要人手校時間軸 |

### F-1 · 點解係 JSON 而唔係 `.ass`

1. **`\kf` 係相對累加值**：Dialogue 入面係 `Start` + 一串 `\kf<時長>`。要郁某個字嘅**開始時間**，要改前一個字嘅時長或插入嘅 `{\k<gap>}`，間接又易錯。JSON 全部係**絕對 ms**，直觀。
2. **`.ass` 抹走咗 `estimated` 資訊**：多字詞被按比例平分（`今晚`→`今`/`晚`）呢件事，寫落 `.ass` 之後**永久消失**。UI 需要佢嚟話畀用戶知邊啲時間軸係估出嚟。
3. `.ass` 亦冇 WordSlot 分組，UI 無得做詞級拖曳。

### F-2 · 三條命令嘅職責邊界（鐵律）

| 命令 | 讀 | 寫 | 會唔會改輸入 |
|---|---|---|---|
| `generate` | 影片 + ASR API | `_timings.json` + `_karaoke.ass` | — |
| `render` | `_timings.json` | `_karaoke.ass` | 淨係加 `--sync-style` 嗰陣先改 json |
| `burn` | 影片 + `.ass` | `_karaoke.mp4` | 絕對唔會 |

⚠️ **`burn` 永遠唔會隱含 render**。呢條係為咗防止「人手改過嘅 ass」被靜默覆寫（災難級 silent clobber）。
UI 改完 json → 必須自己行 `render` → 再行 `burn`。

## 9. CLI 參數 → 本表術語 對照

### `generate`（影片 → json + ass）

| CLI 參數 | 影響嘅名詞 |
|---|---|
| `-i/--input` | 原始 MV → TempAudio |
| `-o/--output-dir` | TimingsDoc 與 KaraokeAss 的落地位置 |
| `--api-key` | 覆寫 `DASHSCOPE_API_KEY` / `.env` |
| `--model` | 預設 `qwen-audio-3.1-asr-flash-filetrans` |
| `-l/--language` | `yue` → **重映射** `'zh'`；其餘原值傳 `language_hints` |
| `--separate-vocals` | 只影響送去做 ASR 嘅音源；**burn 出嚟嘅影片必須保留原聲軌** |
| `--font-name` / `--font-size` | 寫入 `style`（有預設值） |
| `--primary-color` 等 | 寫入 `style`（有預設值） |
| `--max-chars` / `--gap-threshold` | 兜底斷句參數（標點優先之下好少觸發），記喺 `source` 做中繼資料 |
| `--min-clause-chars` / `--min-clause-ms` | **ADR-013**：短句合併門檻（**雙條件**：字數 ≤5 且 時長 <2500ms 先合併；拖長音嘅短句照出一行） |
| `--merge-max-chars` | **ADR-013 修訂**：合併後嘅行不可超 16 字（同兜底嘅 `--max-chars=18` 分開） |
| `--keep-punctuation` | **ADR-013**：字幕保留標點（預設**剝走**：行尾刪、行中變空格 + `{\k<gap>}` 停頓）；`render` 都有呢個參數 |
| `--hold-ms` | 句尾停留；**只喺 generate 生效**，之後變成 `line.end_ms` 絕對值 |
| `--margin-v` | 底部垂直留白 px；`0` = `StyleConfig.resolved()` 按 PlayResY 自動（1080p ≈ 59px）。**generate 有預設值、render 係覆寫**（同 `--*color` 一套機制） |

### `render`（json → ass）

所有 `--font-*`、`--*color` 都係**覆寫**（未提供＝ `None` ＝ 用 json 入面嘅值）。
加 `--sync-style` 會將覆寫一併寫返入 json 做持久。

### `burn`（影片 + ass → mp4）

`-i/--input` 影片、`-s/--subtitle` ass、`-o/--output` mp4。
座標系由 `.ass` 嘅 `PlayResX/PlayResY` 讀出，**唔需要 json**。

## 10. G 組：字幕編輯器 UI 術語 · ADR-014

| 術語 | 定義 |
|---|---|
| **LyricLineView** | 編輯器 in-memory 嘅行（doc dict 形狀）；`ui/models.py` 純函數層存取，UI 唔持有第二份 state（R22） |
| **Estimated 字** | `word.estimated=true` 嘅詞（逐字邊界按比例平分估出嚟）；UI 橙色 + 虛線標示，「只顯示估算字」可篩選 |
| **UndoStack** | Command pattern undo/redo（深度 100，`ui/commands.py`）；結構操作用行級 snapshot、精確操作用差量 |
| **ProgressStage** | generate 分階段回呼 stage ∈ {抽音, 上傳, ASR, 斷句, 渲染, 燒錄}（`ProgressCB`） |
| **PreviewPane** | 大 preview 窗：16:9 畫面 + 字幕疊圖 + 當前字幕卡 + 2fps scrub strip |

| **Respread** | 重新劃分：word [begin,end] 內 char 按字數比例重分 → 清 `estimated`（C4） |
| **分隔條** | 預覽 / 時間軸高度比例拖曳條（30%–75%，V17） |
