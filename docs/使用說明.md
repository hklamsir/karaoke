# 使用說明 — Karaoke 字幕工具（UI + CLI）

呢份文件係幫助頁（UI §5.5）嘅內容來源；`ui/pages/help.py` 讀呢份檔渲染。
文件唔存在時幫助頁會 fallback 顯示內置說明。

---

# 1 · 快速上手

1. **揀片**：主頁「MV 影片」按**選擇…**，ffprobe 會即時顯示解像度同時長
2. **揀屬性**：語言（粵語/中文 預設）、輸出資料夾、樣式（字體/字級/三色/留白）
3. **生成**：按「▶ 開始生成」——五個階段（抽音→上傳→ASR→斷句→渲染）逐個亮；
   **上傳階段 3 秒~3 分鐘屬正常**（視乎網絡）
4. **編輯**：完成後按「立即開啟編輯器」——校時間軸、改錯字、斷句合併
5. **燒錄**：編輯器工具列「🔥 燒錄」——自動 render 最新 .ass + ffmpeg 出 mp4

# 2 · UI 導覽

## 主頁

- **基本**：影片選擇（清除/重選）、語言提示、輸出資料夾、**開啟現有** `*_timings.json`（唔使重跑 ASR）
- **樣式**：字體、字級、唱過色/未唱色/描邊色（色塊 + hex 雙向輸入）、描邊粗幼、對齊、底部留白
- **進階**（預設收埋）：保留標點、每行最多字數、停頓閾值、短句門檻×2、合併上限、句尾停留、人聲分離、儲存 ASR 原始 JSON、ASR 模型
- **即時預覽**：改任何樣式參數即刻重繪（系統字體渲染，唔係 libass 逐像素）
- **進度**：五階段狀態 chip + log 窗（可展開）

## 編輯器

- **歌詞樹**（左上）：一句一行；橙色 = 有估算字；雙擊改字；多選兩行可以合併
- **逐字微調**（左下）：當前行每個字嘅 begin/end（ms）；選中後可用 Spinbox 精確套用
- **大 preview 窗**（右上）：16:9 畫面 + **字幕疊圖**（即時睇字幕位置/字級/顏色）+ 當前字幕卡 + 2fps 縮圖 scrub strip（點擊 seek）
- **時間軸**（右下）：波形 + 逐字方塊 + 播放頭 + 全片概覽；分隔條可拖曳（預覽 30%~75%）

### 時間軸操作

| 操作 | 行為 |
|---|---|
| 滾輪 | 以游標為中心縮放（4 級：0.25×/1×/4×/16×） |
| Shift+滾輪 | 水平捲動 |
| 左鍵點空白 | 游標定位 + 播放 |
| 拖字塊本體 | 整個詞平移 |
| 拖字塊左右邊界 | 精調該字 begin/end |
| 拖空白 | （下期）框選新增歌詞行 |

## 設定

- **DashScope API Key**：優先序 = `--api-key` > 環境變數 `DASHSCOPE_API_KEY` > `.env` > settings.json（UI 寫入唔會蓋過環境變數）
- **FFmpeg / FFprobe 路徑**：預設自動偵測；搵唔到先填
- **預設資料夾**：主頁選片/輸出嘅起始目錄
- **主題**：darkly / superhero / litera
- **縮圖快取**：顯示佔用 + 一鍵清除

# 5 · 工作流

```
generate（CLI/UI）→ *_timings.json（canonical）
                        │
                  [UI 編輯] ← 校時間軸 / 改字 / 斷句合併
                        │
render（CLI / 燒錄時自動）→ *_karaoke.ass（衍生物，唔好人手改）
                        │
burn（CLI/UI）→ *_karaoke.mp4
```

- **timings.json 係唯一真源**：改時間改 json（或用 UI），唔好直接改 .ass —— 下次 render 會無條件覆寫
- 三命令可以各自獨立跑：render 唔使重跑 ASR；burn 淨係食 .ass

# 6 · FAQ

**Q：點解字幕冇標點？**
A：ADR-013 預設剝走（行尾刪、行中變空格 + 停頓）。想要標點用 `--keep-punctuation`（UI：進階 → 保留標點）。

**Q：點解啲字要人手校？**
A：ASR 只畀「詞級」時間軸，多字漢字詞嘅逐字邊界係按比例平分估出嚟（`estimated: true`，
UI 顯示橙色）。實測 57% 嘅字係估算 —— 編輯器嘅主功能就係校呢啲字。

**Q：點解 ASR 每次結果唔同？**
A：ASR 非確定性（同一條片兩次跑可以出 13 句 vs 12 句）。校好嘅 json 記得儲存。

**Q：點解上傳要等 3 分鐘？**
A：音訊上傳到百煉臨時儲存，時長波動大（3 秒~3 分鐘），屬正常。進度條喺呢個階段係轉圈式。

**Q：點解字幕撞埋 MV 自帶字幕？**
A：調大「底部留白」（例如 160px）避開內嵌字幕，喺 preview 窗即時睇效果。

**Q：API key 點放？**
A：推薦環境變數 `setx DASHSCOPE_API_KEY "sk-xxxx"`；或者設定頁填（存 `~/.karaoke/settings.json`，唔入 repo）。

**Q：燒錄出嚟嘅片字幕完全冇顯示？**
A：九成係 ASS 時間戳格式問題（`M:SS.cc` 會畀 libass 當秒數）。本工具 `ms_to_ass_time`
已強制 `H:MM:SS.cc` —— 如果係人手改過 .ass 就要檢查格式。

# 7 · 已知陷阱

| 陷阱 | 說明 |
|---|---|
| ASS 時間戳 | 必須 `H:MM:SS.cc`；寫 `M:SS:cc` libass 會解讀錯，輸出冇字幕嘅片（ADR-005） |
| Windows 冒號 | 路徑直接寫入 `ass=<path>` 會爆（`C:` 係 filter 分隔符）；本工具用 cwd + 檔名解決（ADR-006） |
| `language_hints` 毒藥 | `yue` 係「粵語→普通話」開關；本工具重映射為 `zh`（ADR-001） |
| `paraformer-v2` 假時間軸 | 佢嘅「100% 逐字」係線性插值；已永久禁用（ADR-004） |
| v1 舊 json | 標點黐喺 text 尾；讀入自動相容拆出嚟，只 warn |
| tkinter 縮圖 | PhotoImage 唔支援 JPEG；縮圖一律 PNG |
